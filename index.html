Ligação ao Gist

A aplicação usa um único ficheiro JSON dentro do Gist. Para escrever, cria um token fine-grained com acesso apenas a Gists (leitura e escrita) e com data de expiração (ou um token clássico só com o âmbito gist). O token fica neste browser, nunca no ficheiro HTML.
É a sequência no fim do URL do Gist.
Menos seguro em computadores partilhados. Se desmarcado, desaparece ao fechar o separador.
Após guardar, apagar ou marcar como ouvido, tenta sincronizar com o Gist ao fim de 600 ms. Em caso de falha ou conflito, os dados ficam guardados neste dispositivo.

Apagar álbum?

Se a gravação automática estiver ativa, esta ação será sincronizada após a confirmação. Se falhar, continuará guardada neste dispositivo.
